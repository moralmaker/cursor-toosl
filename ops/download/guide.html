使用帮助

按系统安装 Cursor TOOLS，配置模型后开启接管。首次配置或升级 Cursor 后需要完全退出并重新打开 Cursor，再新开对话。

通用步骤

  1. 打开 下载页，按设备提示下载对应安装包。
  2. 启动 Cursor TOOLS，打开 Cursor 配置，按提示初始化并信任本地 CA。
  3. 在模型设置中添加服务地址、API Key 和模型名称，保存后点 测试。
  4. 测试通过后保持 Cursor TOOLS 运行，再打开接管开关。
  5. 完全退出 Cursor 再重新打开，新开一个对话，在模型列表中选择已配置的模型。不要选 Auto（Auto 只用官方模型）。

API Key 和模型配置只保存在本机。请求会发到你填写的上游服务，请遵守对应服务商的计费与隐私规则。

macOS

下载的是什么

Mac 安装包是 .tar.gz 压缩包，例如 Cursor.Tools_1.0.1_aarch64.app.tar.gz。这是 Tauri 更新器用的标准格式，不是已经解压好的 .app。解压后才会得到 Cursor Tools.app。

安装

  1. Apple 芯片选 Apple 芯片包，Intel Mac 选 Intel 包。不确定时看「关于本机」里的芯片信息。
  2. 双击压缩包，或在终端执行 tar -xzf Cursor.Tools_*.app.tar.gz。
  3. 把解压出的 Cursor Tools.app 拖到「应用程序」。
  4. 首次打开若提示无法验证开发者：系统设置 → 隐私与安全性 → 仍要打开。

使用

  1. 打开 Cursor TOOLS，完成 CA 初始化和模型测试。
  2. 开启接管。应用会关闭并重新启动 Cursor，使代理配置生效。
  3. 在 Cursor 新对话里选择你配置的模型。

应用内更新同样下载这份 .app.tar.gz，由程序自动替换已安装的应用，无需再手动解压。

Windows

选哪个包

  • 安装版（*_x64-setup.exe）：推荐。安装后可从开始菜单打开，并支持应用内自动更新。
  • 便携版（cursor-tools-*-windows-amd64.zip）：解压即可运行，不必安装。适合不想写入系统目录的情况。

安装版

  1. 运行安装程序，按向导完成安装。
  2. 从开始菜单打开 Cursor TOOLS。
  3. 若 SmartScreen 拦截，选择「更多信息 → 仍要运行」。

便携版

  1. 解压 ZIP，运行其中的 cursor-tools-desktop.exe。
  2. 不要把解压目录放到需要管理员权限才能写入的位置，否则便携更新会失败。

使用

  1. 完成 CA 初始化、模型测试后开启接管。
  2. 若 Cursor 没有自动重启，请完全退出 Cursor（托盘图标也要退出）后再打开。
  3. 新开对话并选择已配置模型。

Linux

选哪个包

  • AppImage：通用，多数发行版可直接运行。
  • deb：Debian / Ubuntu 及衍生版。
  • rpm：Fedora / RHEL 及衍生版。

AppImage

  1. chmod +x Cursor.Tools_*.AppImage
  2. ./Cursor.Tools_*.AppImage

deb / rpm

  1. Debian / Ubuntu：sudo dpkg -i Cursor.Tools_*.deb，缺依赖时再执行 sudo apt-get install -f。
  2. Fedora / RHEL：sudo rpm -i Cursor.Tools-*.rpm 或使用发行版的软件包管理器安装。

使用

  1. 启动后完成 CA 信任（可能需要输入管理员密码）。
  2. 配置并测试模型，开启接管。
  3. 完全退出 Cursor 再打开，新开对话选择已配置模型。

常见问题

为什么 Mac 下载按钮不是 .app？

发布产物是压缩后的应用程序包 .app.tar.gz。解压一次即可得到 Cursor Tools.app。应用内自动更新也使用同一文件，由程序解压并替换。

开启接管后 Cursor 没有起来？

手动打开 Cursor 即可。配置已经写好，重新启动后生效。若仍未接管，先关掉接管再打开一次，确保会走关闭并重启流程。

对话里看不到自己的模型？

确认 Cursor TOOLS 仍在运行、测试已通过、已完全重启 Cursor，并且新开了对话。不要使用 Auto。

如何和官方账号一起用？

在 Cursor 中登录自己的账号。有官方额度时，官方模型与本地模型可以切换。没有官方额度时，请手动选择本地配置的模型。
